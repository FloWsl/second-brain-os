# The prompts from the video 💬

## Write your `AGENTS.md` (tip 4)

```
Read this folder and write me an AGENTS.md at the root. Make it a routing table: each folder, what's in it, when to use it, and where to save new things. A map, not a manual. Keep it under 200 lines.
```

## Build a dashboard on top of your second brain (tip 11)

```
Build me a dashboard on top of my second brain that shows my top 3 priorities for today, the decisions we made this week, what each person on my team is working on, and my meetings for today with a 3-line prep for each.
```

## Make your skills read from your second brain (tip 12)

```
Build or update this skill so every reference file points to the right file in my second brain, instead of saving a copy inside the skill.
```

## The business-first rule for your `AGENTS.md` (tip 18)

```
Always act in the best interest of the business, based on our goals and strategy. If a request or output conflicts with that, say so clearly instead of just agreeing.
```
